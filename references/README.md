# References

Company-wide external material: benchmarking, market research, competitor analysis, articles —
anything sourced from outside Keeis that doesn't belong to one specific pipeline stage or
project (those keep their own `references/` folders for stage-scoped material).

- Name: `YYYY-MM-DD-topic.md`, source attribution required (link or citation).
- Capture only. If a finding should shape strategy, note it in `_config/current-strategy.md`;
  if it should become a decision, propose an entry for `_config/decisions.md`.
- Read-only once saved, per `CLAUDE.md` rule 3 — append findings, don't rewrite history.
